# Gestion de stock – Boulangerie

Application web pour gérer le stock et les ventes d’une boulangerie sur tablette.

- Ajouter des produits et enregistrer les entrées, les pertes et les corrections de stock.
- Saisir les ventes au fil du service ou en une seule fois en fin de journée.
- Consulter le chiffre d’affaires et les quantités vendues par jour.

## Lancer le projet

Avec Node.js 22 ou supérieur, lancer les commandes suivantes dans le dossier du projet :

```bash
npm install
npm run dev
```

Ouvrir l’adresse affichée dans le terminal, généralement `http://localhost:5173`.

Cette version utilise React et Vite. Les données sont enregistrées dans le navigateur.
